## 🚀 Key Features
1. **Interactive Homepage**:
   - Full-width cinematic hero with dark navy overlay
   - Floating trip enquiry planner card
   - Verified 4-statistic trust bar (5.0 Google Rating, 198 Reviews, Personalized Planning, Domestic & Global Coverage)
   - Popular tour packages (Kashmir, Goa, Kerala, Rajasthan, Dubai, Thailand, Singapore, Europe, Himachal, Bali)
   - 5 premium service cards
   - 6 why choose us value pillars
   - Google customer testimonials with direct review links
   - High-conversion CTA banner

2. **Dedicated Pages**:
   - **Tour Packages**: Search, category filters, duration filters, budget filters, sorting
   - **Domestic Tours**: North, South, West, East, and Northeast India tours
   - **International Tours**: Asia, Middle East, Europe, Africa, Australia packages with visa and flight guidance
   - **Car Rental & Taxi Hire**: Fleet showcase (Hatchback, Sedan, SUV, Luxury, Tempo Traveller) + Interactive Fare Calculator for local, outstation, and airport transfers (Ahmedabad AMD & Vadodara BDQ)
   - **About Us**: Authentic company profile, philosophy, and Dakor roots
   - **Contact Us**: Interactive enquiry form, direct phone/WhatsApp buttons, and Google Maps location embed

3. **Admin Content Management Portal (`#admin`)**:
   - Secure passcode authentication (default: `admin123`)
   - Tour package manager (add, edit pricing, update images, delete)
   - Car rental fleet manager (add/edit vehicles, rates, capacities)
   - Customer enquiry inbox (view leads, update status, 1-click WhatsApp/Call response)
   - Business settings editor (phone, address, business hours, Google reviews count)

4. **Omnichannel Enquiries**:
   - Floating WhatsApp button with pre-filled trip enquiry builder
   - Click-to-call direct links
   - Universal enquiry modal with localStorage backup and direct WhatsApp handoff

## 🛠️ Tech Stack
- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Build Tool**: Vite 8
- **SEO**: Schema.org JSON-LD (TravelAgency / LocalBusiness), Open Graph tags, robots.txt, sitemap.xml

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/shivanshtechnologies/Alex-Tours-and-Travels.git
cd Alex-Tours-and-Travels
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production
```bash
npm run build
```
